# StarHeart

[English](./README.en.md) · **中文**

**给 AstrBot 的长期记忆。** 把聊天记下来，聊到相关的事时自动想起来 —— 顺带维护人物 / 群聊画像、关系与表达习惯。

## 它是怎么工作的

装好之后它就在旁边听着：消息照常收、照常回（它不插话、也不改原有的回复），只是顺手把值得记的东西整理成记忆存到本地；下一轮开口之前，再把可能相关的几条翻出来交给模型参考。

## 功能

- **长期记忆**：对话整理成一条条记忆存进本地数据库；太久没被用到的会自然变淡、归档，不会越堆越乱。
- **相关回忆**：每轮对话自动挑出跟当前话题有关的记忆，让模型记得住你说过的事。
- **人物 / 群聊画像**：按人、按群整理成「这是个什么样的人 / 群」，可以自动更新。
- **关系与好感**：日常互动累积关系值，分档影响说话语气。
- **表达习惯**：从聊天里学说话方式，越聊越像。
- **主动开口**（可选）：一段时间没人说话，它可以自己开一句。
- **撤回记录**：谁撤回了什么会被记下来（含图片留档）。
- **可视化面板**：记忆图谱、记忆库、消息事件、人格管理、设置 —— 一整套自带面板。

## 安装

两种都行，任选一种：

1. **在 AstrBot 里装**（推荐）：插件 → 安装插件 → 搜索 `StarHeart`；或者选「从 URL 安装」，填本仓库地址。
2. **手动装**：下载本仓库，把 `astrbot_plugin_starheart` 文件夹放进 `data/plugins/`（这一层里要能直接看到 `main.py`），然后重启 AstrBot 或在插件管理里点「重载」。

装好后到插件页打开它的配置和面板就行。

## 数据

记忆、画像、好感、配置都存在本地 `data/plugin_data/astrbot_plugin_starheart/` 下；除了你自己配置的模型接口，插件不向任何第三方发送数据。
